# Exercise 5: Library Management System (Comprehensive Challenge)

## Objective

Build a complete library system integrating all concepts: structures, file I/O, search, and updates.

## System Requirements

### Data Structures

**Book:**
- ISBN (int)
- Title (string)
- Author (string)
- Year published (int)
- Available (boolean/int)

**Member:**
- Member ID (int)
- Name (string)
- Books borrowed (array of ISBNs)

### Core Functions

**Book Management:**
1. Add new book
2. Display all books
3. Search by title/author
4. Mark as borrowed/returned

**Member Management:**
1. Register new member
2. Display all members
3. Search member

**Transaction Management:**
1. Borrow book (check availability, update records)
2. Return book
3. Display member's borrowed books

**File Operations:**
1. Save books to file
2. Load books from file
3. Save members to file
4. Load members from file

## Challenge Features

- Input validation
- Error handling
- Menu-driven interface
- Data persistence
- Search optimization

This is the capstone exercise - use everything you've learned!
